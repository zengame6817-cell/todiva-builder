# 東ディバ編成ビルダー

スマホ向けの非公式編成支援Webアプリ。静的ファイルだけで動作します。

## 機能

- 所持カード登録、戦力入力（1〜9999万）
- にゃんうぉ：1班×6枚、闘技場・怪異事件：4班×6枚
- 班内の同一カード重複防止、班戦力・総戦力の自動計算
- 前衛1〜4／後衛5〜6のプレビュー、スキル枚数と配置条件の確認
- 複数ビルド保存、選択したビルドのURL共有、閲覧・コピー・未所持表示
- JSONバックアップ・復元、図鑑・ヘルプ

## GitHubで公開する手順

1. GitHubに任意の名前（例：`todiva-builder`）でリポジトリを作成します。
2. このフォルダーの中身をリポジトリの直下に追加します。隠しフォルダー `.github` も必要です。
3. 既定ブランチを `main` にします。
4. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。
5. Actions の **Publish GitHub Pages** を開き、**Run workflow** で実行します。以後はmainへの更新時にも公開されます。
6. 成功後、Settings → Pages に表示されるURLを開きます。

設定の詳細：[GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

通常の公開URLにはGitHubのユーザー名が含まれます。名前を含めたくない場合は、個人名を含まないアカウント名を使うか、取得済みの独自ドメインを設定してください。`zen.game` の取得・接続はこのセットには含まれません。

## ローカルで使う

Node.jsを用意し、このフォルダーで `node scripts/serve.mjs` を実行して `http://127.0.0.1:4173` を開きます。HTMLファイルの直接起動ではなくHTTPで開いてください。

`node scripts/test.mjs` で編成・戦力・共有・バックアップ・スキル集計の検証を実行できます。

## データと保存

カード共通情報は `dist/data/cards.json` です。画像ファイルは同梱せず、Wiki側の画像URLを参照します。各カードの `image` を変更すると差し替えられます。

手持ち・戦力・編成・保存ビルドはブラウザのlocalStorageに保存します。別端末・別ブラウザ・別ドメインへ移る場合は、移動前にバックアップし、移動先で復元してください。共有URLには選んだビルドの内容が含まれます。

前衛は1〜4、後衛は5〜6です。エントリー系には後衛からの増援が条件のスキルがあります。スキル枚数は配置カードの集計であり、戦闘中の発動回数を保証しません。

## カード情報の更新

Pythonとbeautifulsoup4を用意し、[Wiki全カード一覧](https://tekuwiki.cloudfree.jp/%e5%85%a8%e3%82%ab%e3%83%bc%e3%83%89%e4%b8%80%e8%a6%a7/)を `list.html` として保存して `python scripts/update_cards.py` を実行します。詳細ページは `cache/` に保存されます。再取得時は該当キャッシュを削除します。

## 出典・権利

本アプリは公式サービスではありません。カード情報の出典は東京ディバンカー攻略Wikiです。ゲーム画像・名称・スキル文章等の権利は各権利者に帰属します。出典表記や画像URL参照だけで利用許可を得たことにはなりません。公式への利用許可は未確認です。

このフォルダーは公開準備用です。GitHubへのアップロード・Web公開はまだ行っていません。現在の別サービス上のサイトに設定された閲覧制限はGitHub Pagesには引き継がれません。公開リポジトリではコード・カードデータを第三者が取得できます。
